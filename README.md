## 🚀 Professional Local Setup (VS Code)

To make the AI Chatbot and Video work on your computer, follow these exact steps:

### 1. The Environment Setup
Browsers don't have `process.env` by default. We use **Vite** to handle this professionally.
1.  **Install dependencies**:
    ```bash
    npm install
    ```
2.  **Create a `.env` file** in the main folder.
3.  **Add your API Key**:
    ```text
    VITE_API_KEY=your_gemini_api_key_here
    ```

### 2. Run the App
Instead of using Live Server, use the professional dev terminal:
```bash
npm run dev
```
Click the link (usually `http://localhost:5173`) to open the app.

### 3. Permissions
Ensure you click **ALLOW** for Camera and Microphone when prompted, or the Live Shanti and Mood Scanner features will be disabled.
